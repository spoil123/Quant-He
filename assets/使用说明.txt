量化-何 QuantDesktop 桌面版使用说明
=====================================

【启动】
双击 QuantDesktop.exe 即可（首次启动较慢，属正常）。
无需安装 Python、MySQL 或任何依赖。

【包含内容】
- QuantDesktop.exe        桌面应用（FastAPI + Vue3 内置）
- config/                 策略与因子配置（可直接改 YAML，改前自动备份）
- outputs/final5/         2021-2025 全市场面板缓存（约 1.9 GB，组合回测的离线数据源）
- 本说明文件

【核心功能：组合回测】
导航栏 →「组合回测」：
1. 勾选成员因子（5 个达标因子任选）并调整组合权重
2. 可选：等权 / custom 权重、TopN、单票上限、回测区间
3. 点「保存并回测」，约 10 秒出结果（净值、绩效、调仓明细）
4. 每次运行的配置快照保存在 outputs/final5/combo_config_*.json，可追溯

【其他功能】
- 总览 / 回测：Top50 五因子策略历史回测（需本机 MySQL 时才能重跑，查看历史产物不需要）
- 因子：IC 汇总、分层收益、IC 时间序列
- 因子配置：改因子方向 / 权重后重跑 Top50（需 MySQL）
- 风控与监控：风控前后对比、数据健康巡检（需 MySQL）

【常见问题】
- 双击没反应：看同目录 startup.log（每次启动都会追加日志）
- 提示端口占用：默认用 8000 端口，被占用时先关掉占用进程，
  或设置环境变量 QUANT_WEB_PORT 换端口
- 组合回测报"面板缓存缺失"：确认 outputs/final5/panel_cache_2125.pkl 存在
- 想用需数据库的功能：自行安装 MySQL 8.0 并按项目 README 初始化数据
