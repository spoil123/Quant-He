## 四、方法论说明

- 多空夏普与纯多头夏普口径不可混用：本批因子为排除型 alpha（G1 显著差、G5 不比 G4 好），多空不是其正确用法，详见 Combo3 验证报告
- 已知数据缺口：`dv_ttm`（股息率）列缺失，"红利"成分实际未生效（缺失填中性值），待补数据重估
- 成本模型未做实盘逐笔校准，滑点按保守档计
